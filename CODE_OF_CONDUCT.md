# Code of Conduct

We want LinuxFeel for Mac to be a respectful, useful public project.

## Expected behavior

- Be courteous and collaborative.
- Keep feedback focused on code, docs, and behavior.
- Respect privacy and avoid doxxing, harassment, threats, or discrimination.
- Do not share secrets, credentials, or other sensitive information.

## Unacceptable behavior

- Harassment or abusive language.
- Publishing private data or unrelated personal information.
- Deliberately misleading or harmful conduct.
- Repeated disruption of reviews or discussions.

## Enforcement

Maintainers may remove content or participation that violates this code of
conduct.

If you need to raise a concern, use the repository's published reporting path
or open a private security report when the issue is security-sensitive.
