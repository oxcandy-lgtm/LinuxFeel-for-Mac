# Security Policy

LinuxFeel for Mac is a small public OSS utility project.

## Reporting

If GitHub Security Advisories are enabled for this repository, please use that
private reporting path for security-sensitive issues.

If advisories are not available, use the repository's published security
reporting process instead of opening a public issue for secrets, credentials,
private infrastructure details, or other sensitive data.

## Scope

This project is intended to remain public-surface clean.

- Do not report secrets or private keys in public issues.
- Do not post private hostnames, IPs, or local-only paths.
- Do not include personal data or unrelated private project context.

## Warranty

The project is provided "as is" without warranty. Use caution before enabling
system-wide helpers or automation on hardware you have not tested.
